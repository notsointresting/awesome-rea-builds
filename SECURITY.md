# Security and safe use

Entries link to third-party repositories. **They are not security-audited or endorsed.** Review source before installation. Do not run untrusted binaries on your personal or production machine without appropriate safeguards. Never provide credentials or proprietary software to an untrusted analysis service.

CI validates catalog data and builds static HTML. It does not download, build or execute third-party software. Malware distribution, credential extraction, piracy and privacy-invasive submissions are excluded.

Report security concerns using a GitHub issue without secrets, or use GitHub private vulnerability reporting if enabled.
